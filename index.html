사용법

전달에서 호출까지, 네 단계.

테이블에 뭘 붙일 필요도, 앱 다운로드도 없습니다. 링크 하나면 오늘 저녁부터 바로.

01

링크 전달

웨이터가 손님에게 접속 링크를 문자로 보내거나, QR로 연결합니다.

02

손님이 접속

손님이 링크나 QR로 들어오면 호출·부킹·주류 버튼 화면이 열립니다.

03

요청 신청

버튼 한 번이면 손님이 무엇을 원하는지 즉시 전달됩니다.

04

웨이터 알림

웨이터 폰에 소리·진동과 함께 알림. 누가 무엇을 요청했는지 한눈에.

웨이터의 하루

손님 부르기부터 장부까지,
밤 전체를 커버합니다.

손님이 오기 전, 와 있는 동안, 가고 난 뒤 — 웨이터의 영업 사이클 전부를 폰 하나로.

오기 전 — 손님 부르기

부를 손님을
만든다.

VIP 골라서 단체 문자 한 번. 불금·명절·계절에 맞는 문구는 앱이 알아서 추천합니다.

  • 단체 문자 한 번에 발송
  • 날짜 맞춤 문구 자동 추천
  • 생일·안 온 단골 자동 알림
온 밤엔 — 현장

부킹 원하는 손님,
놓치지 않는다.

손님이 입장 때 부킹 의사를 직접 선택합니다. 매우 원함 손님은 강한 알림으로, 대기 목록은 자동으로 정렬됩니다.

  • 호출·주문 2초 도착
  • 부킹 대기 자동 정렬
  • 매우 원함 우선 알림
가고 나면 — 장부

손님은 가도,
장부에 남는다.

방문 기록·생일·취향·규모가 손님 장부에 쌓입니다. 장부는 웨이터 개인의 것 — 업소를 옮겨도 그대로 갑니다.

  • 손님 장부 자동 축적
  • 방문·메이드 기록
  • 월간 실적 한 장 정리
기능

현장에 필요한 것만, 전부.

나이트 현장의 호흡에 맞춰 설계했습니다.

👑

손님 장부

생일·주종·손님 규모·방문 기록을 손님별로 기록. 이직해도 장부는 웨이터의 것입니다.

⭐

부킹 의사 표시

손님이 입장 때 직접 선택 — 원함·매우 원함. 매우 원함은 팁 안내를 확인한 손님만 표시됩니다.

🔔

부킹 대기

부킹 원하는 손님이 알림 탭에 자동으로 줄을 섭니다. 오늘 밤 누구부터 챙길지 한눈에.

✉️

단체 문자

전체·최근 방문·안 온 단골을 골라 한 번에. 불금·명절·계절 문구를 날짜에 맞춰 자동 추천합니다.

📊

월간 실적

손님 팀 수·메이드·새 VIP·문자 발송을 달마다 집계하고 지난달과 비교합니다.

📅

예약 메모

"금요일에 4명 갈게"를 기록해두면 당일 VIP 탭 맨 위에 자동으로 떠오릅니다.

🎂

생일 챙김

생일 일주일 전부터 자동 알림. 버튼 한 번으로 축하 문자까지 — 재방문이 만들어집니다.

⚡

호출·주문·계산

손님이 자리에서 버튼 한 번 — 호출·맥주 추가·메시지·계산 요청이 2초 안에 웨이터 폰에 도착합니다.

📱

자주 묻는 질문

궁금한 점,
여기서.

손님이 앱을 깔아야 하나요?

아니요. 손님은 받은 링크나 QR로 접속만 하면 됩니다. 설치 없이 브라우저에서 바로 호출·부킹할 수 있어요.

알림 받으려면 따로 기기가 필요한가요?

웨이터 본인 휴대폰이면 충분합니다. 매장에서 공용 태블릿을 써도 되고, 웨이터마다 각자 폰으로 받아도 됩니다.

QR을 테이블에 꼭 붙여야 하나요?

아니요. 붙여도 되지만, 웨이터가 손님에게 문자로 링크를 보내거나 QR로 연결해 주는 방식으로도 됩니다.

인터넷 연결이 필요한가요?

네. 매장 와이파이나 휴대폰 데이터 연결만 있으면 됩니다. 별도 장비나 설치는 필요 없어요.

POS나 다른 장비 없이도 쓸 수 있나요?

네. ncall은 독립적으로 작동합니다. 기존 POS와 무관하게 폰과 인터넷만 있으면 바로 쓸 수 있어요.

VIP 손님 관리도 되나요?

네. 손님 장부에 생일·주로 드시는 술·손님 규모·메모를 기록하고, 방문 이력과 메이드 여부가 자동으로 쌓입니다. 생일이 다가오면 알려주고, 오래 안 온 단골은 위로 띄워줍니다.

정말 평생 무료인가요?

네. 유료 기능이 생기기 전에 가입해 실제로 사용하신 웨이터(손님 등록 이력이 있는 계정)는 평생 무료입니다. 가입만 해두고 사용하지 않은 계정은 대상이 아닙니다. 초기에 함께해 준 분들에 대한 약속입니다.

내 손님 장부는 누가 볼 수 있나요?

웨이터 본인만 봅니다. 업장이나 다른 웨이터에게 공개되지 않으며, 업소를 옮겨도 장부는 그대로 가져갑니다. 장부는 웨이터 개인의 자산입니다.

도입에 얼마나 걸리나요?

가입 1분, 링크 발급 5분이면 됩니다. 별도 설치나 IT 담당자 없이 가입 당일 저녁부터 바로 쓸 수 있어요.

수첩은 이제 그만.
